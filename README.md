# Лабораторная работа №1 · Вариант 14

Вещественный генетический алгоритм для минимизации семимерной функции Стыблинского–Танга. В эксперименте сравниваются две вероятности мутации и равномерный случайный поиск.

## Запуск

Из каталога `lab01` выполни команды. Результаты в репозитории получены на Python 3.13.

```powershell
python -m pip install -r requirements.txt
python experiment.py --seed 2026 --runs 30
```

Скрипт использует последовательные значения `seed` начиная с указанного. `--runs` задаёт число запусков на метод, минимум 20. По умолчанию файлы сохраняются в `results/`. Для новой серии можно указать отдельный каталог, например `--output results_new`.

| Файл | Содержимое |
| --- | --- |
| [Отчёт](report.md) | Постановка, алгоритм, блок-схема и анализ эксперимента |
| [`genetic.py`](genetic.py) | Целевая функция, операторы ГА и случайный поиск |
| [`experiment.py`](experiment.py) | Запуск серий, подсчёт статистики и построение графика |
| [`config.json`](results/config.json) | Параметры и список `seed` |

| [`summary.csv`](results/summary.csv) | Сводная статистика по методам |
| [`convergence.png`](results/convergence.png) | Средние траектории и доверительные интервалы |
